# 源码脱敏范围

仓库由选定的源码目录重新组装，再进行文本检查和密钥扫描，没有导入服务器历史文件或历史 Git 提交。

包含网站程序、静态界面、默认主题图片、数据库结构、依赖清单、助手控制器、运维配置模板及可独立运行的 Python 测试。默认主题照片检查后未发现 EXIF 或 GPS 元数据。

排除以下内容：

- 真实环境文件、会话密钥、管理员密码/哈希、SSH 私钥、TLS 私钥和证书。
- 模型和 GitHub 的认证文件、令牌、配置目录。
- PostgreSQL/SQLite 数据库、数据库导出、业务备份。
- 上传照片、游记、导入的 HTML、生成的攻略、原始业务内容目录。
- 助手任务记录、模型日志、聊天上下文、候选工作目录。
- 部署截图、临时验证数据、运行缓存、虚拟环境和 node_modules。

真实域名与服务器公网地址已替换为示例值；路径和 `travelnotes` / `travelagent` 是可调整的默认部署约定，不包含访问凭据。测试中的固定密码和令牌字符串仅用于隔离测试夹具，不能作为实际账号密码使用。

`.gitignore` 排除常见敏感文件与运行数据。后续提交仍需检查 diff 和新增文件，避免把真实配置或业务数据加入仓库。
